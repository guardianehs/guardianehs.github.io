Projects

What's built, what's being built, and what's still an idea.

Guardian is an EHS management platform assembled from modules rather than one lump of software. Each one exists because a real task needed it. This page is the honest status of all of them — including the parts that are still research.

Live

Permit to work

The module Guardian is built around: type-specific checklists, gas testing, TRA and isolation references, a Draft→Issued workflow, a rule-based offline verdict and a signature-ready print.

Shipped · used daily
Live

Audit & findings register

Set the audit basis, log findings as NC, observation or OFI with owners and dates, attach evidence, print the report.

Shipped
Live

Daily register & KPIs

Fourteen activity metrics per day, day-versus-cumulative KPIs, a 14-day trend, a printable daily report and CSV export for analytics.

Shipped
Live

Offline reference engine

Fifty EHS topics with exact calculators — 5×5 risk, LTIFR and TRIR, gas limits, and threshold rules for depth, height, noise and load. No model required.

Shipped
